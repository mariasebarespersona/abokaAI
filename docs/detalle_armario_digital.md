## 🔧 Implementación Técnica

### Tabla SQL: `armario_documents`

```sql
CREATE TABLE armario_documents (
    id UUID PRIMARY KEY,
    property_id UUID REFERENCES properties(id),
    cajon TEXT CHECK (cajon IN ('COMPRA', 'REFORMA', 'FINANCIERO', 'GESTIONES', 'VENTA', 'CIERRE')),
    subcajon TEXT,
    document_name TEXT,
    storage_path TEXT,
    importe NUMERIC,
    is_placeholder BOOLEAN DEFAULT TRUE,
    is_uploaded BOOLEAN DEFAULT FALSE,
    is_required BOOLEAN DEFAULT TRUE,
    UNIQUE(property_id, cajon, subcajon, document_name)
);
```

### Funciones RPC Disponibles

| Función | Descripción |
|---------|-------------|
| `seed_armario_digital(property_id)` | Crea estructura vacía con todos los placeholders |
| `list_armario_documents(property_id, cajon)` | Lista documentos (opcionalmente filtrado por cajón) |
| `upload_armario_document(...)` | Sube documento y lo vincula a celda |
| `get_armario_summary(property_id)` | Resumen de progreso por cajón |

### Clasificación Automática

Los documentos se clasifican automáticamente según palabras clave en el nombre:

```python
DOC_GROUPS = {
    "COMPRA:Due Diligence": ["nota simple", "catastro", "certificado ibi", ...],
    "COMPRA:Contrato": ["arras", "señal", "escritura compraventa", ...],
    "REFORMA:Contrata": ["contrato obra", "contrato constructor", ...],
    # ... etc
}
```
